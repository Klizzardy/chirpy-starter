## 2. 编写Python脚本

### （1）目标

1. 连接到数据库A和数据库B。
2. 遍历A_A表中的所有行。
3. 对于每一行，使用id在数据库B中的B_B表中查找具有相同id的数据。
4. 如果B_B表中找到的对应行的template_name为`'nostransfer'`，则更新A_A表中相应行的mid值为8。

### （2）代码

```python
import mysql.connector
from mysql.connector import Error

try:
    # 连接到数据库A
    conn_a = mysql.connector.connect(
        host="tkcvs-001-mysql.service.jjsrv.local",
        prot=4306,
        user="dev_cvs_rwl",
        password="VY2abLAyjWdQoMl",
        #charset= "utf8",  # 这一项应该不用
        database="CVS"
    )

    # 连接到数据库B
    conn_b = mysql.connector.connect(
        host="10.30.127.15",
        prot=3306,
        user="root",
        password="wdh24dtfD*!",
        database="CVS"
    )

    # 创建游标对象，用于执行SQL查询	
    cursor_a = conn_a.cursor()
    cursor_b = conn_b.cursor()

    # 执行SQL查询从A_A表中选择所有id。
    cursor_a.execute("SELECT id FROM A_A")
    # 使用fetchall()方法获取所有结果行，这些结果存储在rows_a_a变量中。
    rows_a_a = cursor_a.fetchall()

    # 使用for循环遍历rows_a_a中的每一行。
    # row[0]提取当前行的第一个元素，即id，将其存储在id_a_a变量中。
    for row in rows_a_a:
        id_a_a = row[0]

        # 在B_B表中查找具有相同id的数据
        cursor_b.execute("SELECT template_name FROM t_evt_product_grow_main WHERE id = %s", (id_a_a,))
        # 使用fetchone()方法获取第一行结果并存储在row_b_b变量中。
        row_b_b = cursor_b.fetchone()

        # 如果row_b_b不为空，提取template_name。
        if row_b_b:
            template_name = row_b_b[0]

            # 检查template_name是否为'nostransfer'
            if template_name == 'nostransfer':
                # 更新A_A表中的mid值为8
                cursor_a.execute("UPDATE A_A SET mid = 8 WHERE id = %s", (id_a_a,))
                # 使用commit()提交事务。
                conn_a.commit()

# 捕获并打印任何发生的数据库错误：
except Error as e:
    print(f"Error: {e}")
# 在finally块中，关闭所有游标和数据库连接。
# 确保在脚本结束时释放数据库连接资源，即使发生了错误。
finally:
    if cursor_a:
        cursor_a.close()
    if cursor_b:
        cursor_b.close()
    if conn_a:
        conn_a.close()
    if conn_b:
        conn_b.close()
```

### （3）详细步骤说明

1. **连接到数据库A和数据库B**： 使用`mysql.connector.connect()`方法分别连接到数据库A和数据库B。
2. **获取A_A表中的所有行**： 使用`cursor_a.execute("SELECT id FROM A_A")`查询A_A表中的所有行的id。
3. **遍历获取的所有行**： 使用`for row in rows_a_a:`循环遍历查询结果中的每一行。
4. **在B_B表中查找具有相同id的数据**： 使用`cursor_b.execute("SELECT template_name FROM B_B WHERE id = %s", (id_a_a,))`在B_B表中查找具有相同id的数据。
5. **检查template_name是否为'nostransfer'**： 获取查询结果中的`template_name`，并检查其值是否为`'nostransfer'`。
6. **更新A_A表中的mid值为8**： 如果`template_name`为`'nostransfer'`，使用`cursor_a.execute("UPDATE A_A SET mid = 8 WHERE id = %s", (id_a_a,))`更新A_A表中的相应行。
7. **提交更改和关闭连接**： 提交对A_A表的更改，并关闭所有游标和数据库连接。

这个脚本会遍历A_A表中的每一行，并根据B_B表中的数据更新A_A表中的mid值。请根据实际数据库连接信息和具体表结构调整代码中的数据库名称、表名称、列名称等。
