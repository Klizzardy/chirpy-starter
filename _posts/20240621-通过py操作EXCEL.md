请帮我实现以下逻辑：

在此 python 文件同路径下，有一些.csv 文件，文件名记录在 csv_list 中。

循环该列表，对每一个 csv 文件进行处理：

  csv 文件的格式为：第一列为 key， 第二列为 field，第三列为 value。

  其中，key 形如 "MS:D5849:956535"，需要将该 key 值最右侧 ":" 号右侧的数字提取出来，该数字为 userID。

  field 形如 "58490002_ct"，需要将 "_" 号左侧的数字提取出来，该数字为 eid。

  value 保持不变。

  将上述提取出来的 userID、eid、value 作为三列数据，写入到一个同名的 .xlsx 文件中。





下面是一个Python脚本，它实现了你描述的逻辑。这个脚本使用了`pandas`库来处理CSV文件和写入Excel文件，以及`os`库来处理文件路径。

首先，确保你已经安装了`pandas`和`openpyxl`库，如果没有安装，可以通过以下命令安装：

```bash
pip install pandas openpyxl
```

接下来是Python脚本：

```python
import os
import pandas as pd

# 假设 csv_list 是包含所有CSV文件名的列表
csv_list = ['file1.csv', 'file2.csv', 'file3.csv']

# 遍历 csv_list 中的每个文件
for csv_file in csv_list:
    # 读取CSV文件
    df = pd.read_csv(csv_file)
    
    # 提取 userID 和 eid
    df['userID'] = df['key'].str.split(':').str[-1]
    df['eid'] = df['field'].str.split('_').str[0]
    
    # 移除原始的 key 和 field 列，只保留 userID, eid, value 三列
    df = df[['userID', 'eid', 'value']]
    
    # 构建新的Excel文件名
    xlsx_file = os.path.splitext(csv_file)[0] + '.xlsx'
    
    # 将处理后的数据写入Excel文件
    df.to_excel(xlsx_file, index=False)
```

这段代码首先定义了一个包含所有CSV文件名的列表`csv_list`。然后，它遍历这个列表，对每个CSV文件进行处理：

1. 使用`pandas`的`read_csv`函数读取CSV文件。
2. 使用字符串方法提取`key`列中的`userID`和`field`列中的`eid`。
3. 选择需要的列（`userID`, `eid`, `value`）并移除其他列。
4. 构建新的Excel文件名，通过移除CSV文件名中的扩展名并添加`.xlsx`。
5. 使用`pandas`的`to_excel`函数将处理后的数据写入新的Excel文件。

确保你的环境中已经安装了必要的库，并且`csv_list`中的文件名与实际文件名匹配。运行此脚本后，每个CSV文件都将被转换为一个同名的Excel文件，其中包含提取的`userID`, `eid`, `value`列。
