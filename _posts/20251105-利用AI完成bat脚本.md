# 从40分钟手动筛选到30秒搞定：BAT脚本+AI，打工人的重复劳动救星


上周整理摄影素材时，我被一个机械活困住了——明明是简单的文件筛选，手动操作却要花大半天，最后靠BAT脚本+AI轻松解决，效率直接翻倍。

## 一、我的具体需求
### 1. 项目目录结构
我在电脑里建了一个总文件夹，**完整路径是 D:\摄影项目**，所有文件和脚本都按以下结构存放（和BAT脚本同级）：
```
D:\摄影项目
├── 筛选素材.bat  （我们要运行的BAT脚本）
├── JPG精选/       （存放挑选出来的JPG图）
│   ├── 风景001.jpg
│   ├── 人像002.jpg
│   └── ...（共87个JPG文件）
├── RAW/           （存放相机原始素材）
│   ├── 风景001.NEF
│   ├── 风景001.NEF
│   ├── 人像002.NEF
│   └── ...（共200多个不同格式文件）
└── RAW精选/       （目标文件夹，最终存放匹配的原始素材）
```

### 2. 头疼的手动操作流程
如果手动做，步骤要拆成这样：
1. 打开“JPG精选”，记住第一个文件名 “风景001”（忽略`.jpg`扩展名）；
2. 打开“RAW”文件夹，逐个查找所有包含 “风景001” 的 NEF 文件；
3. 把找到的文件全部复制到 “RAW精选”；
4. 回到 “JPG精选”，换下一个文件“ 人像002”，重复 1-3 步。

上百个文件要逐个核对，至少花 40 分钟，眼睛盯得酸，还容易漏选或错选。

### 3. 最终效果
用 BAT 脚本运行后，30 秒就完成了所有操作：“RAW” 里所有和 “JPG精选” 同名的156个文件，全部自动复制到 “RAW精选”，每个步骤都有清晰提示，不用手动干预。

## 二、零编程基础？AI帮你写好脚本
我完全不懂编程，直接把 “目录结构+需求” 告诉 AI，很快就拿到了可用的脚本，还通过迭代解决了中文乱码的问题。

### 1. 给AI的“精准需求”
“我需要一个BAT脚本，放在D:\摄影项目目录下（目录结构见上文），实现：遍历‘JPG精选’里的所有文件，提取文件名（不含扩展名），把‘RAW’里所有同名（不管扩展名）的文件复制到‘RAW精选’，注意中文文件夹可能乱码。”

### 2. 最终可用的脚本（直接复制就能用）
```batch
@echo off
:: 解决中文乱码，优先UTF-8，失败切换GBK
chcp 65001 >nul 2>&1 || chcp 936 >nul 2>&1
setlocal EnableDelayedExpansion

:: 定义三个文件夹路径（和脚本同目录，对应上面的目录结构）
set "jpg_dir=JPG精选"
set "raw_source=RAW"
set "raw_dest=RAW精选"

:: 检查文件夹是否存在，不存在则提示或创建
if not exist "!jpg_dir!\" (echo 错误："!jpg_dir!"文件夹不存在，检查路径；pause；exit /b 1)
if not exist "!raw_source!" (echo 错误："!raw_source!"文件夹不存在，检查路径；pause；exit /b 1)
if not exist "!raw_dest!\" (echo 创建"!raw_dest!"文件夹；md "!raw_dest!")

echo 开始处理：从"!raw_source!"拷贝同名文件到"!raw_dest!"
echo ------------------------------------------------

:: 核心逻辑：匹配并复制文件
for %%f in ("!jpg_dir!\*.*") do (
    set "base_name=%%~nf"  :: 提取无扩展名的文件名（如"风景001.jpg"→"风景001"）
    echo 处理文件：!base_name!
    set "found=0"
    :: 匹配RAW中所有同名文件（如"风景001.cr2"）
    for %%r in ("!raw_source!\!base_name!.*") do (
        if not "%%~xr"=="" (  :: 确保是文件，不是文件夹
            copy /y "%%r" "!raw_dest!\" >nul
            echo  已复制：%%~nxr
            set "found=1"
        )
    )
    if "!found!"=="0" (echo  未找到匹配文件)
)

echo ------------------------------------------------
echo 处理完成！
pause
```

### 3. 怎么用？3步搞定
1. 打开记事本，把上面的脚本复制粘贴进去；
2. 保存文件，文件名改成“筛选素材.bat”（注意后缀是`.bat`，不是`.txt`）；
3. 把这个`.bat`文件放到 **D:\摄影项目** 目录下（和三个文件夹同级），双击运行，等待完成即可。

## 三、BAT脚本到底是什么？一句话看懂
其实BAT脚本一点不神秘，就是Windows系统自带的 “自动化操作清单”：
- 后缀是`.bat`，不用装任何软件，**Windows 直接支持**；
- 原理很简单：把你手动点鼠标的步骤（复制、重命名等），写成电脑能懂的“指令”，保存后双击，电脑就会自动按顺序执行；
- 核心功能：帮你干 **“重复、机械、费时间**” 的活，比如批量处理文件、一键启动软件。

## 四、打工人必看：BAT脚本的实用场景
除了处理摄影素材，这些日常工作场景用 BAT 也能高效解决：

### 1. 批量整理文件
- 按格式分类：把 “D:\报销凭证” 里的`.docx` `.xlsx` `.pdf`文件，自动分到 “Word” “Excel” “PDF” 三个子文件夹；
- 统一重命名：给“ D:\会议照片” 里的所有图片，加上 “20240520-会议-” 前缀（比如`IMG_1234.jpg`→`20240520-会议-IMG_1234.jpg`）；
- 筛选文件：从 “D:\日志” 里，把包含 “错误” 关键词的文件，复制到 “异常日志” 文件夹。

### 2. 一键启动工作软件
每天上班要逐个打开微信、Chrome、Excel（日报模板）？写个脚本放在桌面，双击全启动：
```batch
:: 启动微信
start "" "C:\Program Files\Tencent\WeChat\WeChat.exe"
:: 启动Chrome并打开工作文档
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" "https://docs.qq.com"
:: 启动Excel日报模板
start "" "D:\工作模板\日报.xlsx"
```

### 3. 自动备份重要文件
担心文件丢失？用脚本+Windows“任务计划程序”，每天18:00自动把“桌面\工作文档”备份到移动硬盘：
```batch
:: 自动备份文件到移动硬盘
xcopy "C:\Users\XXX\Desktop\工作文档" "E:\工作备份\*" /s /e /y
echo 备份完成！
```

### 4. 一键清理系统垃圾
C 盘满了？用脚本清理临时文件、浏览器缓存，不用装第三方工具：
```batch
:: 清理Windows临时文件
del /f /s /q %temp%\*.*
:: 清理Chrome缓存
del /f /s /q "C:\Users\XXX\AppData\Local\Google\Chrome\User Data\Default\Cache\*.*"
echo 清理完成！
```

## 五、总结：工具+AI，让重复劳动自动化
BAT 脚本的核心价值，就是把 “费时间、易出错” 的重复操作交给电脑。而AI的出现，让零编程基础的打工人也能轻松用起来——不用学代码，只要说清目录结构和需求，就能拿到现成脚本。

工作中遇到重复活时，别着急动手，不妨试试 “BAT脚本+AI” 的组合。一个小小的`.bat`文件，就能帮你节省大量时间，把精力放在更有价值的事情上。毕竟，高效工作的关键，就是让工具帮你干杂活～
