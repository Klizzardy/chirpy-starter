## 处理 'creator' 字段

df_122_new_lv2 中 需要新增一个字段 'creator' ，处理逻辑如下：取 df_level_2 中的 'employee_name' 字段，存储为变量 user_name，在同路径文件 user_info.json 中查找 "UserAccount" = user_name 的数据，取 "UserId" 为变量 user_id，将 user_id 写入 'creator' 中。
user_info.json 的内容格式如下：

```json
{
    "data": [
        {
            "UserId": 4,
            "UserAccount": "zhangtao",
            "UserName": "张涛",
            "EmployeeNum": "0122"
        },
        {
            "UserId": 11,
            "UserAccount": "jiht",
            "UserName": "纪洪涛",
            "EmployeeNum": "0360"
        }
    ]
	"success": true,
    "message": "",
    "status": 200
}
```



### 代码解释

```python
df_122_new_lv2['creator'] = df_level_2['employee_cid'].map(
    lambda x: df_user_info[df_user_info['UserAccount'] == x]['UserId'].values[0] 
    if not df_user_info[df_user_info['UserAccount'] == x].empty else None
)
```

1. **`df_level_2['employee_cid'].map(...)`**:
   - 这一部分代码表示对 `df_level_2` 数据框的 `employee_cid` 列应用 `map` 方法。
   - `map` 方法会对 `employee_cid` 列中的每一个值执行指定的函数（这里是一个 `lambda` 函数）。
2. **`lambda x: ...`**:
   - `lambda x` 表示定义一个匿名函数，这个函数接受一个参数 `x`，即 `employee_cid` 列中的每一个值。
3. **`df_user_info[df_user_info['UserAccount'] == x]`**:
   - 这一部分代码表示在 `df_user_info` 数据框中查找 `UserAccount` 列的值等于 `x` 的行。
   - `x` 是当前 `employee_cid` 的值，因此这里查找的是 `UserAccount` 等于 `employee_cid` 的值的行。
4. **`if not df_user_info[df_user_info['UserAccount'] == x].empty`**:
   - 这一部分代码表示检查在 `df_user_info` 数据框中查找 `UserAccount` 列的值等于 `x` 的行是否为空。
   - `not ... .empty` 的意思是，如果查找结果不为空，则执行 `if` 语句后的代码。
5. **`['UserId'].values[0]`**:
   - 这一部分代码表示从查找到的行中提取 `UserId` 列的值。
   - `values` 属性将数据框转换为一个 NumPy 数组，`[0]` 表示取数组的第一个元素。
6. **`else None`**:
   - 如果查找结果为空，则返回 `None`。
7. **赋值给 `df_122_new_lv2['creator']`**:
   - 最终的结果是，将 `map` 方法返回的值（即 `UserId` 或 `None`）赋值给 `df_122_new_lv2` 数据框的 `creator` 列。

### 整体流程

1. 对于 `df_level_2` 数据框中的每一个 `employee_cid` 值，执行 `lambda` 函数。
2. 在 `df_user_info` 数据框中查找 `UserAccount` 列等于当前 `employee_cid` 值的行。
3. 如果找到匹配的行，则提取 `UserId` 列的值。
4. 如果没有找到匹配的行，则返回 `None`。
5. 将结果赋值给 `df_122_new_lv2` 数据框的 `creator` 列。

### 示例

假设 `df_level_2` 中有如下数据：

| numerical_system_id | employee_cid |
| ------------------- | ------------ |
| 1                   | zhangtao     |
| 2                   | jiht         |
| 3                   | unknown_user |

假设 `df_user_info` 中有如下数据：

| UserId | UserAccount |
| ------ | ----------- |
| 4      | zhangtao    |
| 11     | jiht        |

那么，执行这段代码后，`df_122_new_lv2` 的 `creator` 列将会是：

| numerical_system_id | creator |
| ------------------- | ------- |
| 1                   | 4       |
| 2                   | 11      |
| 3                   | None    |

这是因为：

- `zhangtao` 对应的 `UserId` 是 4。
- `jiht` 对应的 `UserId` 是 11。
- `unknown_user` 在 `df_user_info` 中没有匹配项，所以返回 `None`。

### 调试建议

如果代码未能填充 `creator` 字段，可能的原因包括：

- `employee_cid` 列中的值没有在 `df_user_info` 的 `UserAccount` 列中找到匹配项。
- `df_user_info` 数据框的格式或者内容有误。

可以通过打印输出 `df_level_2['employee_cid']` 和 `df_user_info` 来调试问题所在。
